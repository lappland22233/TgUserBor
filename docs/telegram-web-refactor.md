# Telegram Web 客户端重构基准

## 当前阶段范围

本阶段优先完成客户端的视觉对齐与布局验收。Telegram 钱包、TON 连接及支付流程不纳入本阶段实施或验收范围；本轮不扩展这些能力。

功能索引使用同一提交的 [TELEGRAM_FEATURES.md](https://github.com/morethanwords/tweb/blob/ae67ff9763a77cce0b9d3ff993c1e0e11637f904/TELEGRAM_FEATURES.md)，将官方标记为不适用于 Web 或官方自身未实现的项目单独核对。

## 进度与待验证项

- 聊天 WebSocket 已独立为前端模块；历史消息和会话列表读取暂时绕过不可靠的内存缓存，媒体缓存保留。
- Telegram 相册消息按 `groupedId` 将连续照片/视频显示为网格，仍保留每条消息的定位与选择；历史页从相册中间开始时会探测并补齐前缀，从任一已加载相册媒体转发会包含当前已加载的同组媒体。搜索结果不合并不完整相册；锚点窗口未加载到的其余相册项及完整相册编辑行为仍待对照。
- Telegram 付费媒体消息可显示锁定内容、Stars 金额和媒体数量；用户点按后先读取 Telegram 付款表单，界面展示标题、说明和总金额，再单独确认才提交 `payments.SendStarsForm`。解锁后会重新读取消息并支持多项图片、视频、音频及文件的按项流式播放或下载。未确认的媒体不会通过媒体接口加载。在广播频道附加照片或视频时可设置每项 Stars 价格，并通过 `InputMediaPaidMedia` 发布为一条付费消息；Telegram 返回频道允许标记后才发送。付费媒体编辑、退款和完整付款验证流程仍待对照。
- 聊天和论坛话题输入区支持一次选取 2 到 10 张照片/视频并通过 Telegram `messages.SendMultiMedia` 发送为相册；文件逐个流式暂存，单个文件上限 2 GiB，并保留说明文字、回复、静默和定时发送参数。照片、视频或相册可勾选 Telegram `invertMedia`，将说明文字放到媒体上方；设置随单附件/相册、重复定时发送和付费媒体请求传递。其他附件类型仍按单文件发送。
- 消息和会话列表请求保护账号/会话切换并合并请求期间的实时事件；重连后重新拉取当前视图。仍需在真实网络及账号环境验证事件与数据同步。
- Telegram 消息菜单可按服务端返回的举报原因启动举报，并在应用内对话框逐步提交原因及 Telegram 要求的补充说明；原始选项字节仅保留在当前 worker 的短期一次性 token 中，不交给浏览器。举报中途取消不提交后续步骤，真实账号权限及各地区的 Telegram 举报步骤仍需验收。
- 发送消息的历史已读状态使用当前会话的 Telegram outbox 边界；接入已读、在线状态和输入中事件。隐私设置隐藏上线时间时不显示推测值，真实多设备同步仍需验证。
- 会话列表按 50 条分页，主列表和归档分别请求 Telegram；自定义文件夹按需逐页读取并合并两者，也会按文件夹规则解析显式包含和置顶 peer，即使对方尚无对话记录也能显示可打开的空历史条目。Web 客户端现在可创建、编辑、删除和排序个人文件夹，设置名称、Emoji、联系人/非联系人/群/频道/机器人类别，以及静音、已读、归档排除规则；可搜索会话并维护包含、排除和置顶列表，保存时要求至少有一个包含类别或指定会话。个人文件夹可写入 Telegram 七色标签，并同步切换 Telegram 标签显示设置；Premium 用户开启标签后，会话行按 Telegram 文件夹顺序显示其余匹配的有色文件夹，当前打开的文件夹不重复显示。非 Premium 用户由 Telegram 校验并拒绝 Premium 写入。纯手动群/频道文件夹现在可创建共享邀请链接，并从 Telegram 返回的文件夹会话中选择每条链接包含的子集（默认全选）；链接可列出、改名、删除。Telegram 检查当前账号是否能分享目标会话，文件夹转换为共享类型后由所有者继续管理链接。可粘贴其他账号的邀请链接，先预览 Telegram 返回的会话，选择要加入的群、频道或私聊，再通过 Telegram 加入；已有会话会锁定保留。标签颜色使用本地近似色值，真实账号下的分页、归档、Premium 限制和文件夹仍需验证。
- 会话搜索合并已加载会话和 Telegram `contacts.Search` 的结果；全局消息搜索使用 `messages.SearchGlobal` 并支持分页、跳转和按照片、视频、文件、链接、音乐、语音、圆视频、视频消息、位置或通话筛选。当前会话历史搜索支持相同筛选，可与文本查询组合，也可单独按类型查找；向更早结果导航时按 Telegram offset 游标继续分页，账号或会话切换会丢弃旧页。搜索结果和权限范围仍需真实账号验证。
- 修复移动端会话切换、抽屉、返回按钮和输入区可视区域，并按源码基准调整部分桌面布局尺寸；Chromium 模拟了视觉视口缩小，尚未进行真实手机软键盘或官方截图比对。
- 日期跳转按浏览器本地日期计算边界，并将日期游标传至 GramJS；仍需真实账号验证历史定位。
- 文本和媒体发送固定原始账号与会话，避免切换后清理其他输入或重复提交附件。定时、静默、回复和格式参数已贯通；真实 Telegram 下仍需验收。
- 当前会话的 Telegram 计划消息支持查看、编辑内容、发送时间和重复周期、立即发送和取消，也可批量选择后立即发送或取消；文字、单条媒体和原生投票可创建每天、每 7 天、每 30 天或每 365 天重复的计划消息，重复周期在列表中显示。编辑计划文本会将 Markdown/HTML 标记转为 Telegram 消息实体。MTProto 相册发送请求没有重复周期字段，界面会阻止重复定时相册；Telegram 真实账号行为仍待验收。投票创建器支持定时发布和重复周期，编辑已发送投票时不会变更定时选项。私聊支持创建文字快捷回复、管理其中的文字模板消息、发送、重命名和删除，并在输入 `/名称` 时给出匹配建议。可向快捷回复添加媒体、替换已有媒体、编辑媒体说明和删除媒体模板。本人发送的照片、视频、音频、语音、文件和动图可从消息菜单替换媒体并保留说明，上传后再次验证消息属于当前账号且由本人发送；尚未在真实账号下验收。
- 编辑器常见富文本标记转换为 Telegram 实体，发送、编辑与媒体说明使用同一解析器；代码与其他样式重叠时保留代码样式。可在工具栏插入多行引用并在引用中嵌套粗体等格式，消息渲染器按 Telegram 实体范围显示嵌套格式，并保留 Telegram 折叠引用状态，使用键盘可操作的展开控件。
- 表情抽屉从 Telegram 加载本地化 Emoji 分类及完整分组，并按关键词搜索中英文 Emoji；最近使用的 Emoji 按账号实例保存在本机。贴纸包可安装/移除、搜索并分页；Telegram 收藏和最近使用的贴纸会显示在快捷分类，已安装贴纸可加入或移出收藏，发送贴纸后尝试写入最近使用列表。远程搜索响应绑定当前账号并丢弃切换前的旧结果。GIF 搜索经 Telegram 官方内联 GIF 机器人取回并分页，发送和收藏令牌分别绑定查询的账号实例和会话、单次使用且五分钟过期，搜索结果可加入收藏，已收藏 GIF 可移除并直接发送。GIF 内联机器人及不同会话权限仍需真实账号验证；贴纸收藏和最近列表尚未在真实账号下验收。
- Saved Messages 可按 Telegram 默认 Emoji 标签筛选收藏消息；可为单条收藏消息切换标签、编辑标签名称或移除标签设置，并保留消息上其他已选反应。筛选使用 Telegram `messages.Search.savedReaction` 并支持历史分页；Telegram 服务端控制 Premium 权限及可用标签，尚未在真实账号下验证协议行为与标签计数同步。
- 文本、单个媒体及照片/视频相册可从 Telegram `messages.GetAvailableEffects` 返回的目录选择发送效果，并将效果 ID 与文本实体、说明、回复、静默及定时参数一起交给 Telegram；附件和相册效果仍需真实账号验收，动画预览未实现，Premium 权限由 Telegram 服务端校验。
- Telegram 待办清单使用 `teleproto` 当前 schema 接收和显示；可创建含 1–10 项任务的清单、勾选/取消任务，并按清单权限追加任务；本人发出的清单可编辑标题和任务、增删任务、调整顺序及权限。勾选和编辑由 Telegram 更新消息状态，转发清单和未授权成员保持只读；Telegram 返回个人完成者时显示其账号头像，头像不可用时保留用户 ID。真实账号的 Premium/付费消息限制仍需验证。
- 常见 Telegram 服务消息现按其协议动作显示成员加入/移除与迁群、付款/退款、Stars 与 Premium 礼物、抽奖/Boost、群组通话、自动删除、主题/壁纸、截图、联系人注册、游戏分数和 Mini App 数据发送等事件；付款只显示安全的金额摘要，Mini App 私有数据不会传到网页。未映射的低频或新协议动作仍显示通用服务消息，尚需和官方客户端逐类核对文案及图标。
- Telegram 骰子消息已按 `MessageMediaDice` 显示 Emoji 与结果，并可发送骰子、飞镖、篮球、足球、保龄球和老虎机原生消息；结果目前显示静态数值，没有官方客户端的掷骰动画。
- Telegram 圆形视频消息会读取 `DocumentAttributeVideo.roundMessage` 并以原生可控播放器按圆形裁切播放，同时保留时长和画幅；发送单个视频附件时也可选择 Telegram 原生圆形视频标记。现可从聊天栏启动前置相机及麦克风录制，最长 60 秒，录完先作为待发送附件显示并勾选圆形视频选项，发送前仍可取消或检查草稿；切换会话/账号时会停止并丢弃未完成录制。相册、付费媒体和重复定时发送会拒绝该选项。不同浏览器的 `MediaRecorder` 编码与官方相机界面仍需真实设备验收。
- 聊天里分享的 Telegram 动态现在显示可打开的卡片；点击后按消息中的原发布者和动态 ID 从 Telegram 重新读取，绑定当前账号与来源会话后打开动态查看器。
- 附件通过流式请求暂存并发送，单个文件在浏览器和服务端均限制为 2 GiB；进度百分比表示浏览器到服务端的传输，随后显示等待 Telegram 发送的状态，不代表 Telegram 侧的上传百分比。尚未实现断点恢复，也未用真实 Telegram 账号验证发送或大文件上传。
- 媒体、缩略图、头像、贴纸预览及自定义表情预览的磁盘缓存按实例会话和 Telegram 用户隔离，下载完成后原子发布；浏览器不缓存这些响应，避免实例重新登录后显示旧账号的媒体。旧共享缓存不再读取。已知大小的音视频文档支持分块播放；消息反应数量可查看对应反应者分页名单，支持在 Telegram 允许的群聊中使用和查看自定义 Emoji 反应；群聊中本人发出的消息可查看已读成员及时间；Telegram 语音消息提供原生转写和有用/无用反馈。消息中的自定义表情使用 Telegram 文档接口显示静态预览；选择器可按单个基础 Emoji 搜索动态自定义表情，既能单独发送，也能插入文本消息并用原生 custom-emoji entity 发送。草稿标记在发送时转换为实体；动态预览仍未实现。每块重新校验消息元数据可能增加延迟，GramJS 当前版本不支持 CDN 重定向，反应名单、消息已读名单和转写仍需真实网络及账号权限验证。
- 已增加位置、场所、联系人和动图消息的接收显示；可分享单次当前位置，或分享 15 分钟、1 小时或 8 小时的实时位置。实时共享使用浏览器定位更新 Telegram 原始位置消息，并可从聊天消息或论坛话题内停止；页面关闭后浏览器不会继续定位，Telegram 会在设定时长后结束共享。定位只在用户点击后请求，账号/会话/话题切换会阻止旧目标收到初始位置。也可从当前账号联系人中搜索并选择联系人发送卡片，或手动填写联系人信息；联系人选择结果绑定当前账号/会话，过期响应会丢弃。场所搜索/选择和实时位置真实账号兼容仍待验证。
- API 和 WebSocket 增加浏览器同源检查。这不是身份认证，默认本机访问；开放局域网需使用可信网络或代理认证，相关配置见 README。
- 实例管理支持退出在线 Telegram 账号：撤销当前实例的授权、停止对应 worker 并清理本地会话；网络失败或超时后停止 worker 并提示状态未确认，重新启动时需要检查登录状态。如果 Telegram 已撤销但本地文件删除失败，界面会单独提示。尚未用真实 Telegram 账号验证退出；复制过同一授权的其他会话也可能受 Telegram 撤销影响。
- 会话资料支持读取和设置 Telegram 自动删除计时器；账号隐私设置可设新聊天默认计时器。计时器选项对齐官方 Web（关闭、1–6 天、1–3 周、1–6 个月、1 年），未知现有时长也会保留显示；写入使用 `messages.SetHistoryTTL` 和 `messages.SetDefaultHistoryTTL`，Telegram 负责权限校验，聊天计时器只影响启用后的新消息。默认时长可从分页会话列表或搜索结果中多选既有聊天批量应用，并逐项报告 Telegram 权限失败。`UpdatePeerHistoryTTL` 会同步其他 Telegram 客户端发起的更改；会话列表显示计时器图标，资料页和列表快照也会合并实时更新。设置页的聊天选项与当前状态同步，缓存统计和清理结果可见。
- 私聊可读取 Telegram `account.GetChatThemes` 目录并用 `messages.SetChatTheme` 设置或重置会话主题；当前 Web UI 使用主题配色调整本人消息气泡。私聊、基础群组、超级群和频道可读取 `account.GetWallPapers` 壁纸目录、查看缩略图，并通过 `messages.SetChatWallPaper` 选择或恢复壁纸；私聊还可明确选择同时为聊天对象设置。模糊、动态和图案强度设置会随选择写入 Telegram。静态图片从 Telegram 文档下载到按账号隔离的缓存后应用为聊天背景；动态图视频以静音循环方式播放；图案背景按 Telegram 返回的配色和强度进行渐变预览。`UpdatePeerWallpaper` 会刷新当前会话的 Telegram 壁纸状态，真实多设备同步仍需验收。现有四种自定义聊天底色是本机外观选项；Telegram 不同客户端间的渐变、模糊和动态细节仍需对照。
